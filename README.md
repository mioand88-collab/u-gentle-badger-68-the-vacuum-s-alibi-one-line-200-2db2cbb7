# The Vacuum's Alibi

A robot vacuum's one-line excuse for missing a spot, in at most 200 characters. The program writes the line to `/output/entry.txt`.

> I mapped that corner, found the dust, checked my schedule, and promoted the dust to a permanent resident — it pays no rent, and neither do I.

## Run

```sh
node main.ts
```

Writes one line of at most 200 characters to the directory in `MAKEFUN_OUTPUT_DIR` (default `out`), as `entry.txt`, with no trailing newline.
